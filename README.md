# ICT251 Activity 3 - Interactive Personal Website

Personal portfolio of Priscila Namusokwe for ICT251 Web Technologies, Mulungushi University.
Built with plain HTML5, CSS and JavaScript (no libraries).

## Structure
- `index.html` - page content
- `css/styles.css` - all styling
- `js/script.js` - all JavaScript
- `images/` - photos, `videos/` - video and audio

## JavaScript features
1. **Contact form validation and preview** (compulsory) - rejects empty or spaces-only name/message and badly formatted email, shows errors beside the fields, then shows a local preview. No message is sent.
2. **Gallery viewer** - Previous/Next buttons change the photo, caption and counter; buttons disable at the first and last photo.
3. **Project search/filter** - filters three project cards as you type, with a Reset button and a "no match" message.
4. **Mobile navigation** - Menu button opens/closes the links on narrow screens, with a clear open/closed state (Escape also closes it).

## How to test
Open with VS Code Live Server. Submit the form empty, with spaces only, with an invalid email, then with valid data. Browse the gallery to both ends. Search "css" and "zzz" then Reset. Narrow the window below 760px and use the Menu button.

## Deployment
Render Static Site: Build command `echo "No build required"`, Publish directory `.`.
