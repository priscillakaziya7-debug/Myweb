My Learning Plan

My learning plan focuses on improving my HTML, CSS and web development skills through regular practice and small projects.

Steps to Improve My Web Skills

  1. Study HTML structure and practise semantic elements.
  2. Learn CSS layouts, colours and responsive web design.
  3. Build small websites and test them on different screen sizes.
  4. Learn basic JavaScript to add interactivity to my websites.
